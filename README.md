# ЯДРО — сборки

Готовые APK приложения ЯДРО (управление станцией Oukitel BP3000E). Код в отдельном закрытом репозитории.

Приложение само проверяет последнюю сборку здесь («Ещё → Обновления»), сверяет SHA-256 и ключ подписи
и предлагает установить. Вручную: Releases → последняя сборка → `app-release.apk`.

Чужая сборка не установится поверх: Android обновляет приложение только сборкой с тем же ключом подписи.
